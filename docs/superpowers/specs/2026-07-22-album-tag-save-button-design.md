# 相册“保存标注”主按钮状态设计

## 背景

相册标注弹层中的“保存标注”当前呈浅灰底、深色文字。虽然按钮在 `saving=false` 时可以点击，但视觉语义接近禁用态，容易让用户误以为不能保存。

## 目标

- `saving=false` 时，“保存标注”使用相册现有品牌主操作样式：深绿 `#1f6f5b` 背景、白色文字和同色边框。
- `saving=true` 时，按钮继续不可点击，显示“保存中...”，并使用明确的灰色禁用态。
- “取消”继续使用白底、深绿文字和浅色边框，不改变布局、尺寸、文案或事件。

## 设计

`AlbumTagSheet` 继续使用 TDesign `t-button`，但不再依赖宿主全局 `.button` 选择器穿透组件样式隔离。保存按钮显式声明 `theme="primary"`，并通过 `custom-style` 设置品牌色及 TDesign 按钮变量；`saving` 仍同时驱动 `disabled`、禁用 class 和“保存中...”文案。

状态映射：

| 状态 | 可点击 | 文案 | 背景 | 文字 |
| --- | --- | --- | --- | --- |
| `saving=false` | 是 | 保存标注 | `#1f6f5b` | `#ffffff` |
| `saving=true` | 否 | 保存中... | 灰色禁用态 | `#ffffff` |

## 测试

先在小程序静态检查中增加回归断言，要求保存按钮具备 primary 主题、品牌色变量和现有 `:disabled="saving"` 绑定。测试应先因当前按钮缺少显式主操作样式而失败；实现后运行该专项检查、小程序 Node 测试与微信小程序构建。

## 非目标

- 不改变保存条件、标签数据、接口请求或错误处理。
- 不改变取消按钮和弹层布局。
- 不调整项目级 TDesign 主题或其他按钮。
